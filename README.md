# Drive Folder Search

Chrome extension that adds a **"search within this folder"** button to Google Drive.

> Google Drive's native search always searches globally. This extension fixes that.

## Features

- Adds a search button scoped to the current folder
- Injects directly into the Drive UI — feels native
- Lightweight content script, no background process

## Tech Stack

Chrome Extension (Manifest V3), content script + CSS injection

## Install

1. Clone this repo
2. Go to `chrome://extensions/` → Enable Developer Mode
3. Click "Load unpacked" → select the repo folder
